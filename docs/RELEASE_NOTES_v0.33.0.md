# TypesetOK — גרסה 0.33.0 (Living Tzurat HaDaf, Multi-Flow Anchoring & Pre-Press Determinism Hardening)

## סקירת שחרור (Release Overview)
גרסה `0.33.0` מהווה את אחד מאבני הדרך החשובות ביותר בפיתוח **TypesetOK** (תוכנת עימוד שולחנית מקצועית לספרים, טקסטים עבריים וספרי קודש):
1. **עימוד רב-תזרימי חי ("צורת הדף" חיה — Living Tzurat HaDaf):**
   - מימוש מלא מקצה לקצה של עגינה לוגית דו-כיוונית (`MultiFlowAnchorMap`) בין פסקאות הטקסט הראשי (גמרא / מקרא) לפירושים (רש"י, תוספות, תרגום, רמב"ן).
   - אכיפה מחמירה של Invariant 1: מניעת הופעת פירוש לפני העוגן המרכזי שלו (No Commentary Lead).
   - גלישת עמודים מסונכרנת בזמן אמת (Synchronized Pagination Cascading) המקפיצה את הפירושים המקושרים לעמוד הבא ברגע שהטקסט הראשי גולש.
2. **איזון גבהי טורים משותף (Shared Column Height Balancing):**
   - אלגוריתם מתקדם לאיזון קו בסיס תחתון משותף בעמודים מקבילים, עם קפיצים אלסטיים אנכיים וחלוקה הרמונית של מרווחי שורות ופסקאות.
   - בקרת יתומים ואלמנות קפדנית גם בפסקאות פירוש ארוכות הנפרסות על פני שבירות עמוד.
3. **הקשחת מנוע הדטרמיניזם וקדם-דפוס (Deterministic Pre-Press Hardening):**
   - הבטחת שחזור ביט-אחר-ביט מוחלט בייצוא קובצי ISO PDF/X-1a ו-HTML בכל סביבות ההרצה.
   - סילוק תלויות גיבוב רנדומליות במבני נתונים (`BTreeMap` ו-`BTreeSet` במקום `HashMap` ו-`HashSet` בליבת העימוד והגופנים).
4. **אוטומציית CI/CD ושחרור גרסאות:**
   - איחוד תהליכי הבדיקה ב-CI והבטחת הרצה יציבה, מקבילית ומהירה.
   - מנגנון Release Workflow אוטומטי המייצר חבילות התקנה, מתקין Windows רשמי וקובצי בינארי עם כל עליית גרסה.
